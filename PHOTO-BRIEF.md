# Photographies nécessaires pour la V2

Douze entrées photographiques sont configurées, réutilisées dans quinze emplacements sur les pages. Aucun visuel de remplissage, photographie fictive ou image d’Opto n’est utilisé. L’absence de photographie n’empêche ni la navigation ni les tests.

Les entrées du carrousel sont réutilisées dans les trois premières cartes de la section Références. Les douze entrées peuvent utiliser onze photographies distinctes si celle de Justice est aussi réutilisée sur Performing Systems. Le choix des artistes du carrousel peut évoluer selon les photos et les droits disponibles, sans attribuer de rôle technique non confirmé.

Pour les concerts : fichiers haute définition, idéalement au moins 2400 px de large, avec suffisamment de marge pour un recadrage mobile. Pour les panoramas : format horizontal large. Pour le matériel : vue lisible sur fond simple ou détourage autorisé, sans inventer de produit. Préférer des WebP/JPEG optimisés pour les photos, PNG/WebP transparents pour les détourages.

Pour chaque image : sujet, projet concerné, crédit du photographe et autorisation d’utilisation. Pour toute description d’intervention : périmètre validé par Playback Solutions. Les images d’Opto servent exclusivement de référence de composition et ne doivent pas devenir des contenus du site.
